# AI 레시피 추천 API

로그인이 필요한 API는 Header에 JWT를 포함해야 합니다.

Authorization

Bearer JWT_TOKEN

------------------------------------------------------------------------

## AI 레시피 추천

### URL

GET http://localhost:3000/api/recipes/recommend

### Header

Authorization

Bearer JWT_TOKEN

### Body

없음

### 설명

- 로그인한 사용자의 냉장고 재료를 조회합니다.
- 현재 재료만으로 만들 수 있는 레시피를 최대 3개 추천합니다.
- 재료가 1~2개 부족하면 만들 수 있는 레시피를 최대 2개 추천합니다.
- 레시피는 Groq AI API를 이용하여 생성됩니다.
